# Code of Conduct

This project adopts the **[Contributor Covenant, version 2.1][covenant]**.

It is adopted by reference rather than copied in, so that the text you are held
to is the canonical one and cannot drift from it through a stale vendored copy.
Read it there; it is short.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## In short

Be decent. Assume the other person is acting in good faith and is missing
context rather than being obtuse. Disagree about the code, not about the
person writing it.

## Enforcement

Report unacceptable behaviour to **emerson@netdevopsbr.com**. Reports are
handled privately, and the reporter's identity is not disclosed to the person
reported.

The Covenant's [Enforcement Guidelines][guidelines] describe the escalation
path — correction, warning, temporary ban, permanent ban — and are what will be
applied.

[guidelines]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines

## Scope

This applies in the project's own spaces — issues, pull requests, discussions,
commit messages, and code review — and when someone is representing the project
elsewhere.
